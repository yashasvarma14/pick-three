    How it works

    13agents
    ~25 sper search, most steps in parallel
    ~$0.006LLM cost per search
    43automated tests, run offline against mocked APIs
    1. 1

      Plan

      Read the request, decide which agents to run.

      Planner with a checked plan

      The LLM proposes agents; Python enforces a dependency graph and a call budget.

      Request → structured JSON

      Group size, budget, likes, dislikes, a time ("this afternoon") and map searches.

      Head start

      Weather and events start in background threads right away.

    2. 2

      Search

      Find real places around you.

      Boxed Google Maps searches

      Several searches at once, limited to a box sized from your drive time.

      Catalog ideas by meaning

      For open-ended requests, outings from a 196-activity dataset ranked by embedding similarity.

      0.70 semantic + 0.15 group + 0.10 budget + 0.05 category
      Polite retries

      On "too many requests", wait 1, 2, 4, 8 s plus jitter.

    3. 3

      Score

      Rank every place found, 50–75 of them, with plain math.

      Fit by cosine similarity

      all-MiniLM-L6-v2 embeddings of the request vs. each place.

      sim(q,p) = q·p / (‖q‖‖p‖), rescaled to 0.3–1.0
      Bayesian-adjusted rating

      A 5.0 from 12 reviews shouldn't beat a 4.7 from 3,000.

      (v·r + m·C) / (v + m), m = 40, C = median ≤ 4.4
      Weighted pre-score + weather

      Outdoor places are discounted when the forecast is bad.

      0.45 fit + 0.25 quality + 0.20 near + 0.10 open
      Entity resolution

      Duplicate listings and chain branches merged by name tokens, website and distance.

    4. 4

      Check

      Look closer at the best dozen.

      LLM validator

      Drops places that only sound related; batches of 4 checked in parallel.

      keep if relevance ≥ 0.60, else check the next batch
      Live traffic + opening hours

      Google Routes drive times; weekly hours turned into minute-of-week intervals.

    5. 5

      Evidence

      Read and look at the finalists, both at the same time.

      Reviews + website RAG

      Scrape, chunk, embed, retrieve; the LLM judges from those passages only.

      700-char chunks, 120 overlap, coverage-aware top-k
      Photo vibe

      A vision model rates the atmosphere in Google Maps photos when the look matters.

      vibe ∈ [0, 1], 0.5 if unclear
    6. 6

      Rank & explain

      Pick three and say why.

      Re-normalized weights

      A missing signal is dropped, never filled in with a guess.

      Σ wᵢsᵢ / Σ wᵢ, w = 40 · 25 · 15 · 20 · 15
      Greedy diverse picks

      No two of one business, a cap per kind of place.

      Grounded write-up

      Must return the exact ranking or it's rejected.
