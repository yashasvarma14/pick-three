    Under the hood

    How it works

    Not one chatbot guess: thirteen small agents, each checking one thing, most of them at the same time.

    1. 01

      Plan

      A planner reads your request and decides which specialists are worth calling: weather, events, photos.

    2. 02

      Search

      Several Google Maps searches run around you at once, boxed to how far you're willing to drive.

    3. 03

      Check

      The best candidates get a closer look: does it really fit, is it open, live traffic, reviews, and how it looks in photos.

    4. 04

      Pick

      Plain math ranks the finalists and an LLM explains the top three, without being allowed to change the order.
